# แผนลดน้ำหนักพยาบาลเข้าเวร (PWA)

เว็บแอปที่ติดตั้งบน iPhone และ Android ได้เหมือนแอปทั่วไป เปิดเต็มจอ มีไอคอนบนหน้าจอโฮม และใช้ได้แม้ไม่มีเน็ต

## ไฟล์ในชุดนี้

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `index.html` | ตัวแอปทั้งหมด |
| `manifest.webmanifest` | ชื่อแอป ไอคอน สีธีม |
| `sw.js` | ทำให้ใช้ได้ตอนออฟไลน์ |
| `icons/` | ไอคอนแอป |
| `firebase-config.js` | ค่าตั้ง Firebase (ไม่ใส่ก็ใช้ได้) |
| `firestore.rules` | กฎความปลอดภัยของฐานข้อมูล |
| `worker/ai-proxy.js` | ตัวกลาง Cloudflare Worker: ใช้กับ AI เมื่อแชร์แอป และจำเป็นสำหรับ Garmin / Strava (ข้อ 9) |

## ระดับการตั้งค่า

| ระดับ | ทำข้อ | ได้อะไร |
|---|---|---|
| พื้นฐาน | 1–2 | แอปครบทุกหน้า เก็บข้อมูลในเครื่อง ใช้ออฟไลน์ได้ |
| + บัญชี Google | 3 | ล็อกอินด้วย Google ซิงก์ข้อมูลหลายเครื่อง |
| + Gmail | 4 | ส่งรายงานรายสัปดาห์เข้า Gmail |
| + AI | 5 | อ่านตารางเวรจากรูป ถ่ายรูปอาหาร สร้างเมนูด้วย AI |
| + นาฬิกา | 9 | ดึงการนอน การออกกำลังกาย พลังงานที่ใช้ จาก Garmin, Strava, Zepp |

ใช้เวลาตั้งค่าครบทุกข้อประมาณ 30–45 นาที ทุกขั้นทำบนคอมพิวเตอร์จะง่ายที่สุด

## 1. เอาขึ้นเว็บฟรีด้วย GitHub Pages (10 นาที)

1. สมัครบัญชีที่ github.com (ถ้ายังไม่มี)
2. กด **New repository** ตั้งชื่อ เช่น `weight-plan` เลือก **Public** แล้วกด **Create repository**
3. กด **uploading an existing file** ลากไฟล์และโฟลเดอร์ทั้งหมดในชุดนี้ลงไป (ให้ `index.html` อยู่ชั้นบนสุด) แล้วกด **Commit changes**
4. ไปที่ **Settings → Pages** ตรง Branch เลือก `main` และ `/ (root)` แล้วกด **Save**
5. รอ 1–2 นาที จะได้ที่อยู่แอป เช่น `https://ชื่อผู้ใช้.github.io/weight-plan/`

> ใช้ Netlify หรือ Vercel แทนได้ ลากโฟลเดอร์ทั้งโฟลเดอร์ไปวางในหน้าเว็บของเขาก็ได้ที่อยู่ทันที

## 2. ติดตั้งบนมือถือ

**iPhone / iPad**
1. เปิดที่อยู่แอปใน **Safari** (ต้องเป็น Safari)
2. กดปุ่ม **แชร์** (สี่เหลี่ยมมีลูกศรชี้ขึ้น)
3. เลือก **เพิ่มไปยังหน้าจอโฮม** แล้วกด **เพิ่ม**

**Android**
1. เปิดที่อยู่แอปใน **Chrome**
2. กดปุ่ม **ติดตั้ง** ที่แอปขึ้นให้บนหน้าวันนี้ หรือเมนู ⋮ → **ติดตั้งแอป** / **เพิ่มลงในหน้าจอหลัก**

**ย้ายข้อมูลจากเวอร์ชันใน Claude:** ในแอปเดิม ไปที่ตั้งค่า → สำรองข้อมูล → **คัดลอกข้อมูลทั้งหมด** แล้วในแอปใหม่ ไปที่ตั้งค่า → **กู้คืนจากข้อความ** วางแล้วกด **กู้คืน**

## 3. ล็อกอินด้วย Google และซิงก์ข้อมูล (Firebase, ฟรี)

1. ไปที่ console.firebase.google.com กด **Create a project** ตั้งชื่อ ปิด Google Analytics ได้
2. ในหน้าโปรเจกต์ กดไอคอน **</>** (Web) ตั้งชื่อแอป กด **Register app** ไม่ต้องติ๊ก Hosting
3. คัดลอกค่าที่ขึ้นมา (`apiKey`, `authDomain`, `projectId`, `appId`) ไปใส่ใน `firebase-config.js` แบบนี้:
   ```js
   window.FIREBASE_CONFIG = {
     apiKey: "AIza...",
     authDomain: "ชื่อโปรเจกต์.firebaseapp.com",
     projectId: "ชื่อโปรเจกต์",
     appId: "1:...:web:..."
   };
   ```
   ค่าเหล่านี้เปิดเผยได้ ไม่ใช่รหัสลับ ความปลอดภัยอยู่ที่กฎในข้อ 6
4. เมนูซ้าย **Build → Authentication → Get started** แท็บ **Sign-in method** → **Google** → เปิด **Enable** เลือกอีเมลติดต่อ แล้วกด **Save**
5. ยังอยู่ใน Authentication แท็บ **Settings → Authorized domains** กด **Add domain** ใส่ `ชื่อผู้ใช้.github.io`
6. เมนูซ้าย **Build → Firestore Database → Create database** เลือกตำแหน่ง `asia-southeast1 (Singapore)` เลือก **production mode** แล้วไปที่แท็บ **Rules** วางเนื้อหาจากไฟล์ `firestore.rules` กด **Publish**
7. อัปโหลด `firebase-config.js` ที่แก้แล้วขึ้น GitHub ทับไฟล์เดิม
8. เปิดแอป ไปที่ **ตั้งค่า → เข้าสู่ระบบด้วย Google**

ข้อมูลในเครื่องจะถูกอัปโหลดขึ้นบัญชีในครั้งแรก ถ้าบัญชีมีข้อมูลอยู่แล้ว (เช่น เข้าจากเครื่องที่สอง) แอปจะใช้ข้อมูลในบัญชีแทน

## 4. ส่งรายงานเข้า Gmail

ต้องทำข้อ 3 ก่อน แล้วไปที่ console.cloud.google.com และเลือกโปรเจกต์เดียวกับ Firebase (ชื่อเดียวกัน)

1. **APIs & Services → Library** ค้นหา **Gmail API** แล้วกด **Enable**
2. **APIs & Services → OAuth consent screen** (หรือ **Google Auth Platform**)
   - **Audience:** ปล่อยเป็น **Testing** แล้วเพิ่มอีเมล Gmail ของคุณใน **Test users** (เพิ่มได้สูงสุด 100 คน)
   - **Data access:** กด **Add or remove scopes** แล้วเลือก `.../auth/gmail.compose`
3. ในแอป ไปที่ **ตั้งค่า → รายงานผลรายสัปดาห์** ใส่อีเมลผู้รับ แล้วกด **ส่งรายงานทาง Gmail** หรือ **สร้างฉบับร่าง**
4. ครั้งแรก Google จะเตือนว่า "Google ยังไม่ได้ยืนยันแอปนี้" ให้กด **ดำเนินการต่อ** เพราะเป็นแอปของคุณเอง แล้วกดอนุญาตสิทธิ์ Gmail

สิทธิ์ Gmail อยู่ได้ 1 ชั่วโมง พอหมดอายุ แอปจะขอเข้าสู่ระบบใหม่ตอนกดส่งครั้งถัดไป

## 5. เปิดใช้ AI

แอปรองรับ AI 2 แบบ เลือกได้ที่ **ตั้งค่า → ตั้งค่า AI → ผู้ให้บริการ AI**

**แบบที่ 1: Google Gemini (ฟรี แนะนำ)**
1. ไปที่ aistudio.google.com ล็อกอินด้วยบัญชี Google
2. กด **Get API key → Create API key** แล้วคัดลอกคีย์ที่ขึ้นต้นด้วย `AIza`
3. ในแอป ไปที่ **ตั้งค่า → ตั้งค่า AI** เลือก **Google Gemini** วางคีย์ เลือกโมเดล กด **บันทึก** แล้วกด **ทดสอบ**

- **Gemini Flash** อ่านรูปตารางเวรและรูปอาหารได้ดี ใช้เป็นค่าเริ่มต้น
- **Gemini Flash-Lite** เร็วกว่าและโควตาฟรีต่อวันมากกว่า ถ้าขึ้นว่าใช้เกินโควตาให้สลับมาใช้ตัวนี้ หรือรอวันถัดไป
- แบบฟรี Google อาจนำข้อมูลที่ส่งไปใช้ปรับปรุงบริการ ไม่ควรส่งรูปที่มีข้อมูลผู้ป่วย

**แบบที่ 2: Anthropic Claude (เสียเงินตามการใช้)**
1. ไปที่ console.anthropic.com สมัครแล้วเติมเครดิตใน **Billing**
2. **API Keys → Create Key** แล้วคัดลอกคีย์ที่ขึ้นต้นด้วย `sk-ant-`
3. ในแอป เลือก **Anthropic Claude** วางคีย์ เลือกโมเดล กด **บันทึก** แล้วกด **ทดสอบ**
- ดูราคาล่าสุดที่หน้า pricing ของ Anthropic ถ้าอยากประหยัดให้ใช้ Haiku ตั้งวงเงินสูงสุดต่อเดือนได้ที่ **Billing → Limits**

**ทั้งสองแบบ**
- คีย์เก็บในเครื่องนั้นเท่านั้น ไม่ซิงก์ขึ้นบัญชี ต้องใส่ทุกเครื่องที่ใช้
- **ห้ามแชร์แอปที่ใส่คีย์ให้คนอื่น** ถ้าจะแชร์ให้ใช้ข้อ 6 (proxy ใช้กับ Claude)

## 6. (ไม่บังคับ) แชร์แอปให้เพื่อนพยาบาลใช้ AI โดยไม่เปิดเผยคีย์

1. สมัคร dash.cloudflare.com → **Workers & Pages → Create → Worker** แล้ววางโค้ดจาก `worker/ai-proxy.js` กด **Deploy**
2. **Settings → Variables and Secrets** เพิ่มค่าเหล่านี้:
   - `ANTHROPIC_API_KEY` (Secret): คีย์ของคุณ
   - `APP_TOKEN` (Secret): ตั้งข้อความยาวๆ เดายาก เช่น `nurse-2026-xyz...`
   - `ALLOWED_ORIGIN` (Text): `https://ชื่อผู้ใช้.github.io`
3. ในแอป ไปที่ **ตั้งค่า AI → ใช้ AI proxy แทนคีย์** ใส่ที่อยู่ Worker (`https://....workers.dev`) และ `APP_TOKEN` แล้วบอกค่าสองอย่างนี้ให้เพื่อน

ทุกคนจะใช้เครดิตจากคีย์ของคุณ ควรตั้งวงเงินสูงสุดไว้ด้วย

## 7. อัปเดตแอปภายหลัง

แก้ไฟล์แล้วอัปโหลดทับใน GitHub จากนั้นเปลี่ยนค่า `VERSION` บรรทัดแรกของ `sw.js` เช่น `v2-2026-12-01` มือถือจะโหลดเวอร์ชันใหม่เมื่อเปิดแอปครั้งถัดไป ถ้ายังเห็นเวอร์ชันเก่า ให้ปิดแอปแล้วเปิดใหม่ 1–2 ครั้ง

## 8. แจ้งเตือนเวลาเปิดและปิดช่วงกิน IF

ไปที่ **ตั้งค่า → IF อดอาหารเป็นช่วง** เลือกโหมด IF และเวลาเริ่มกินของแต่ละเวร แล้วตั้งการเตือนในส่วน **แจ้งเตือนเวลาเปิดและปิดช่วงกิน** ตั้งได้ว่าเตือนตอนเปิดช่วงกินกี่นาทีก่อน (ตรงเวลา, 10, 30 นาที) เตือนก่อนปิดช่วงกินกี่นาที (15–60 นาที) และสร้างล่วงหน้ากี่สัปดาห์ (2, 4, 8)

**ทางที่ 1: เพิ่มลงปฏิทินในมือถือ (แนะนำ เตือนได้แม้ปิดแอป)**
1. กด **ดาวน์โหลดไฟล์ปฏิทิน (.ics)** แอปจะสร้างช่วงกินของทุกวันตามตารางเวร (วันเวรควบที่พัก IF จะไม่มี) พร้อมเตือน 2 ครั้งต่อวัน
2. **iPhone:** เลือก **เพิ่มทั้งหมด** ในหน้าที่ขึ้นมา หรือเปิดไฟล์จากแอป **ไฟล์**
3. **Android / Google Calendar:** เปิด calendar.google.com บนคอมพิวเตอร์ แนะนำให้สร้างปฏิทินใหม่ชื่อ **IF** ก่อน แล้วไปที่ **ตั้งค่า → นำเข้าและส่งออก** เลือกไฟล์และเลือกปฏิทิน IF
4. **เมื่อเวรเปลี่ยน:** ลบปฏิทิน IF เดิมแล้วนำเข้าไฟล์ใหม่ (ใน Google Calendar ถ้านำเข้าวันเดิมซ้ำ รายการจะถูกอัปเดตเอง)

**ทางที่ 2: แจ้งเตือนจากแอป**
- ติ๊ก **เปิดการแจ้งเตือนในแอป** แล้วกดอนุญาต แอปจะเตือนตอนเปิดช่วงกิน ก่อนปิด และตอนเริ่มช่วงอด
- บน iPhone ต้องติดตั้งแอปลงหน้าจอโฮมก่อน (iOS 16.4 ขึ้นไป)
- **ข้อจำกัด:** เตือนได้เฉพาะตอนแอปเปิดอยู่หรือเพิ่งสลับไปแอปอื่น ถ้าปิดแอปไปแล้วจะไม่เตือน จึงควรใช้ทางที่ 1 คู่กัน

## 9. เชื่อมนาฬิกา: Garmin, Strava, Zepp

แอปจะดึงการนอน การออกกำลังกาย และพลังงานที่ใช้ทั้งวัน แล้วสรุป **พลังงานที่ใช้ − พลังงานที่กิน** ต่อวันที่หน้า **วันนี้** และรายสัปดาห์ที่หน้า **ติดตาม** (ต้องบันทึกการกินด้วย)

| แหล่ง | ได้อะไร | วิธีเชื่อม |
|---|---|---|
| Garmin | พลังงานทั้งวัน การนอน ก้าว กิจกรรม | Personal API key + Worker (ดึงเองอัตโนมัติ) |
| Strava | กิจกรรมและพลังงานต่อกิจกรรม (ไม่มีการนอน) | เข้าสู่ระบบ Strava + Worker (ดึงเองอัตโนมัติ) |
| Zepp / Amazfit | การนอน ก้าว พลังงาน กิจกรรม | ส่งออกไฟล์จากแอป Zepp แล้วนำเข้า (Zepp ไม่มี API ให้คนทั่วไป) |

ถ้ากิจกรรมเดียวกันมาจากหลายที่ (เช่น นาฬิกาส่งไป Strava ด้วย) แอปจะเก็บไว้รายการเดียว

### 9.1 สร้าง Cloudflare Worker (ครั้งเดียว ใช้ร่วมกับ AI ได้)

Garmin และ Strava ไม่ให้หน้าเว็บเรียกข้อมูลตรง และ Strava ต้องใช้รหัสลับที่ห้ามอยู่ในแอป จึงต้องมีตัวกลางฟรีนี้

1. สมัคร dash.cloudflare.com → **Workers & Pages → Create → Worker** ตั้งชื่อ แล้ว **Deploy**
2. กด **Edit code** ลบโค้ดเดิม วางโค้ดทั้งหมดจาก `worker/ai-proxy.js` แล้ว **Deploy** (ถ้าเคยสร้างไว้สำหรับ AI ให้วางโค้ดใหม่นี้ทับ)
3. **Settings → Variables and Secrets** เพิ่ม:
   - `APP_TOKEN` (Secret): ข้อความยาวๆ เดายาก
   - `ALLOWED_ORIGIN` (Text): `https://ชื่อผู้ใช้.github.io` (ไม่มี / ท้าย)
   - ถ้าใช้ Strava เพิ่ม `STRAVA_CLIENT_ID` (Text) และ `STRAVA_CLIENT_SECRET` (Secret) จากข้อ 9.3
   - ถ้าใช้ AI Claude ผ่าน Worker เพิ่ม `ANTHROPIC_API_KEY` (Secret)
4. ในแอป ไปที่ **ตั้งค่า → เชื่อมนาฬิกาและแอปสุขภาพ → ตัวกลาง Cloudflare Worker** ใส่ที่อยู่ Worker (`https://....workers.dev`) และ `APP_TOKEN`

### 9.2 Garmin

1. บนคอมพิวเตอร์ เข้า connect.garmin.com → **ตั้งค่า → Personal API Key** (หรือเปิด connect.garmin.com/app/settings/personalApiToken)
2. สร้างคีย์ เลือกอายุ 1 ปี แล้วคัดลอก (Garmin แสดงคีย์ครั้งเดียว)
3. ในแอป วางคีย์ในช่อง **Personal API key** แล้วกด **ดึงข้อมูล 30 วัน**
- คีย์เก็บในเครื่องนั้นเท่านั้น ต้องใส่ทุกเครื่อง Garmin จะส่งอีเมลเตือนก่อนคีย์หมดอายุ
- Personal API ใช้กับบัญชีของตัวเองเท่านั้น เพื่อนแต่ละคนต้องสร้างคีย์ของตัวเอง

### 9.3 Strava

1. เข้า strava.com/settings/api สร้างแอป ช่อง **Authorization Callback Domain** ใส่ `ชื่อผู้ใช้.github.io`
2. คัดลอก **Client ID** และ **Client Secret** ไปใส่ใน Worker ตามข้อ 9.1 ข้อ 3
3. ในแอป กด **เชื่อมต่อ Strava** อนุญาตให้อ่านกิจกรรม แล้วแอปจะกลับมาดึงข้อมูลเอง
- แอป Strava ที่สร้างใหม่ให้เชื่อมได้เฉพาะเจ้าของบัญชีนักพัฒนา ถ้าจะให้เพื่อนใช้ ต้องขอเพิ่มจำนวนผู้ใช้กับ Strava
- พลังงานต่อกิจกรรมมาจาก Strava ถ้า Strava ไม่มีค่า (เช่น ไม่มีชีพจร) แอปจะประมาณจากเวลาออกกำลังแทน

### 9.4 Zepp / Amazfit

1. แอป Zepp → **โปรไฟล์ → ตั้งค่า** → หาเมนู **ส่งออกข้อมูล (Export data)** เลือกช่วงวันที่ แล้วดาวน์โหลดไฟล์ .zip
2. ไฟล์มักล็อกรหัสผ่านที่แอปแสดงให้ แตกไฟล์ด้วยรหัสนั้น (บนคอมพิวเตอร์ง่ายที่สุด)
3. ในแอป **ตั้งค่า → Zepp / Amazfit** เลือกไฟล์ .csv ทั้งหมด (ACTIVITY, SLEEP, SPORT) ถ้า zip ไม่มีรหัส เลือกไฟล์ .zip ได้เลย
- ต้องนำเข้าใหม่เองเป็นระยะ เช่น สัปดาห์ละครั้ง

### อ่านตัวเลขอย่างไร

- **ใช้ไป**: พลังงานทั้งวันจากนาฬิกา ถ้าไม่มีนาฬิกาจะใช้ค่าประมาณจากเวรและการออกกำลัง วันนี้ยังไม่จบ จึงใช้ค่าคาดการณ์ทั้งวันและบอกว่านาฬิกานับได้เท่าไหร่แล้ว
- **กิน**: จาก "บันทึกการกิน" หน้าวันนี้
- **ใช้ − กิน** เป็นบวก = ใช้มากกว่ากิน (ช่วยลดน้ำหนัก) ราว 7,700 kcal ≈ ไขมัน 1 กก.
- นาฬิกาประมาณพลังงานคลาดได้ ±10–20% ให้ดูแนวโน้มน้ำหนักเฉลี่ยรายสัปดาห์ประกอบด้วย

## ข้อจำกัดที่ควรรู้

- **บลูทูธ (นาฬิกาแบบส่งชีพจร, ตาชั่งมาตรฐาน Bluetooth):** ใช้ได้บน Android (Chrome) และคอมพิวเตอร์ ใช้บน iPhone ไม่ได้เพราะ Safari ไม่รองรับ ใช้การนำเข้าไฟล์ .tcx หรือ .csv จากนาฬิกาแทนได้
- **ดึงข้อมูลจาก Apple Health / Google Health Connect อัตโนมัติ:** เว็บแอปทำไม่ได้ ต้องทำเป็นแอปบน App Store / Google Play ระหว่างนี้ใช้ Garmin, Strava หรือไฟล์จาก Zepp ตามข้อ 9
- **การแจ้งเตือนจากแอป (ข้อ 8 ทางที่ 2):** เตือนได้เฉพาะตอนแอปเปิดอยู่ ถ้าต้องการให้เตือนตอนปิดแอปด้วย ให้ใช้ไฟล์ปฏิทิน (ทางที่ 1) หรือตั้งเซิร์ฟเวอร์ Web Push เพิ่ม
- **ไม่ได้ล็อกอิน:** ข้อมูลอยู่ในเบราว์เซอร์ของเครื่องนั้นเท่านั้น ถ้าล้างข้อมูลเบราว์เซอร์ข้อมูลจะหาย ควรล็อกอิน (ข้อ 3) หรือใช้ปุ่ม **คัดลอกข้อมูลทั้งหมด** สำรองไว้เป็นระยะ
- **ความปลอดภัย:** แอปนี้ช่วยวางแผน ไม่ใช่คำแนะนำทางการแพทย์ ถ้ามีโรคประจำตัวหรือกินยาอยู่ ควรปรึกษาแพทย์ก่อน
